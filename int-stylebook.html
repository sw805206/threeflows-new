Stylebook

Generated from STYLE.md v036 / STYLE.css v040. Hidden page, not in nav — reachable by URL only. Every example links the live STYLE.css, and each swatch's hex is read at runtime from its own computed colour, so neither the colours nor the printed values can drift from the tokens. Regenerate per PROCESS.md when a STYLE version adds, removes, or renames a token — the swatch/specimen set is manual; the values self-update.

Colour

The core palette is the logo's four inks; charts and tags draw on the data palette. --tf-white and --tf-footer-ground are named scoped exceptions, not relaxations (STYLE.md §2).

Core inks

--tf-brick

Brand accent — primary actions, kickers, emphasis. Use sparingly; text on brick is always paper.

--tf-ink

Body text, 2px rules, dark surfaces (footer, hero bands).

--tf-stone

Supporting tone — meta text, chart fills, muted labels, borders.

--tf-paper

The ground. Warm off-white — the page is never pure white.

Ink & brick variants

--tf-brick-dark

Brick hover / pressed state.

--tf-brick-on-ink

Brick adjusted for dark (ink) grounds.

--tf-ink-soft

Secondary text.

--tf-stone-light

Light borders, subtle within-section rules (--tf-rule-light).

Named surface exceptions (scoped)

--tf-white

Header chrome only — never a content ground. The one sanctioned pure white.

--tf-cream

color-mix(stone-light 15%, paper). Raised tint — dropdowns, popovers, menus.

--tf-footer-ground

color-mix(ink 75%, stone). Scoped — footer band + band-4 Runningmate header. Tone, not a line.

--tf-ink-raised

color-mix(ink 80%, stone). Raised dark surface — the CTA secondary button.

Structural tones

--tf-sand

Major-section divider tone (--tf-rule-sand). A 2px line, not a field.

--tf-sand-wash

Alternating band tint — a page-width field, lighter than the sand rule.

Typography

Two families. No italics anywhere in the brand — Space Grotesk ships no italic, so emphasis is <strong> or sentence structure (STYLE.md §3).

Source Serif 4

--tf-font-heading

'Source Serif 4', Georgia, serif — weights 600–700. Wordmark, headlines, pull quotes. Advisory, human register.

Space Grotesk

--tf-font-body

'Space Grotesk', 'Helvetica Neue', Arial, sans-serif — 400 body · 500 labels/buttons · 700 stats. Quietly technical.
